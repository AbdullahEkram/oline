# 🚀 منظومة مكتب ITI Online للخدمات الرقمية والحكومية

نظام إداري وخدمي متكامل لمكتب **ITI Online** تحت إدارة **م/ عبدالله التركي (ملوي)**.

## 🌟 مميزات النظام
- **دليل خدمات شامل:** تغطية الأقسام الأربعة (تكريمات وشهادات، خدمات حكومية، تجهيز عروسة وعناية، خدمات رقمية).
- **إدارة أداء الموظفة رضوى مصطفى:** تسجيل ومتابعة الرسائل اليومية، الجروبات، والعملاء الجدد مع حاسبة فورية للرواتب والبونص والخصومات.
- **ربط أونلاين مجاني:** ربط مباشر وغير متزامن مع Google Sheets لحفظ البيانات فورياً.
- **توافق تام:** متجاوب مع كافة الأجهزة الهواتف والتابلت وأجهزة الكومبيوتر.

## ⚙️ طريقة التشغيل على GitHub Pages
1. اذهب إلى **Settings** داخل مستودع GitHub الخاص بك.
2. اختار من القائمة الجانبية **Pages**.
3. في قسم **Source** اختر **GitHub Actions** أو الفرع `main`.
4. اضغط **Save** وسيكون الموقع متاحاً على الرابط:
   `https://<your-username>.github.io/iti-online-system/`
